# Format (one entry per line, `::`-delimited, 5 fields):
#   <check>::<key>::<added>::<added-by>::<justification>

# <check> is one of: mechanism-absent, gate-script-missing, gate-not-wired,

# <key> is <file>:<line>:<token> -- the file relative to the repo root, the

# field count, an unknown check name, an empty key, or an empty

# stale entry (its check::key no longer trips anything) is also a hard
# failure -- see scripts/check_doc_facade.py's module docstring.
