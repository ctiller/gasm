# scripts/check_doc_facade.py Allowlist
#
# Format (one entry per line, `::`-delimited, 5 fields):
#   <check>::<key>::<added>::<added-by>::<justification>
#
# <check> is one of: mechanism-absent, gate-script-missing, gate-not-wired,
# theorem-fence-absent.
# <key> is <file>:<line>:<token> -- the file relative to the repo root, the
# 1-based line number, and the flagged identifier/script/exe name. For
# mechanism-absent / gate-* the line number is counted AFTER fenced-code-block
# stripping; for theorem-fence-absent it is the raw file line of the
# declaration header inside the fence (that check does not strip fences --
# fences are its subject).
#
# Justification is free text and must be non-empty. A line with any other
# field count, an unknown check name, an empty key, or an empty
# justification is a hard parse failure, never a silently-skipped line. A
# stale entry (its check::key no longer trips anything) is also a hard
# failure -- see scripts/check_doc_facade.py's module docstring.
#
# Do not widen this file to reach green. Deliberate placeholder or prohibited
# examples use `text` fences rather than pretending to be implemented Lean;
# all actual Lean-shaped design claims must be implemented or truthfully staged.
