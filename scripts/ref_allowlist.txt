# Law 1 / Law 3 Declaration-Coverage Allowlist
#
# Format (one entry per line, `::`-delimited, 5 fields):
#   <relative-file-path>::<declaration-name>::<fully-qualified-name>::<category>::<justification>
#
# - <relative-file-path>::<declaration-name> mirror scripts/gate_allowlist.txt's
#   convention: the source file and the bare, unqualified declaration name,
#   carried for human readability / diagnostics.
# - <fully-qualified-name> is what Tools/CheckRefsCoverage.lean (the
#   load-bearing declaration-coverage gate) actually matches against --
#   exactly as Lean's compiled environment names it -- combined with the
#   module derived from <relative-file-path> (same module-qualified keying
#   scripts/gate_allowlist.txt/Tools/CheckGatesAxioms.lean already use, for
#   the same reason: a bare fqn is not unique project-wide once more than
#   one module can declare the same short name).
# - Justification is free text and may itself contain `::`; the parser
#   splits with a bounded field count so that never breaks the format.
#
# category is one of:
#   derived-scaffolding  - a declaration that IS independently visible to
#                            Tools/CheckRefsCoverage.lean's environment scan
#                            (so it was not already excluded by that tool's
#                            projection/aux-recursor/no-confusion/containment
#                            filters) but is still mechanical scaffolding
#                            around an already-cited declaration, not an
#                            independently invented concept -- e.g. a
#                            `deriving`-generated instance whose containing
#                            structure carries the real citation.
#   internal-helper       - a small, self-evidently trivial declaration
#                            (a local constant, a one-line arithmetic helper)
#                            that does not introduce a citable concept of its
#                            own -- used sparingly; when in doubt, cite it.
#   grandfathered          - predates Law 1's mechanical enforcement via this
#                            tool and is tracked migration backlog, not a
#                            permanent exemption.
#
# Lines starting with '#' and blank lines are ignored.
