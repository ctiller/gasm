# Target Specification: x86-32 (IA-32 Protected Mode)

This document defines the machine state model, instruction encodings, and semantics for 32-bit x86 Protected Mode (**IA-32**).

---

## 1. Machine State Model

### 1.1 General Purpose Registers (GPRs)
8 32-bit general-purpose registers:

| 32-bit | 16-bit | 8-bit Low | 8-bit High | Standard Usage |
| :--- | :--- | :--- | :--- | :--- |
| `EAX` | `AX` | `AL` | `AH` | Accumulator / Return value |
| `ECX` | `CX` | `CL` | `CH` | Loop counter / `thiscall` pointer |
| `EDX` | `DX` | `DL` | `DH` | Data register / High 32-bit return |
| `EBX` | `BX` | `BL` | `BH` | Callee-saved base register |
| `ESP` | `SP` | — | — | Stack pointer |
| `EBP` | `BP` | — | — | Frame pointer |
| `ESI` | `SI` | — | — | Source index (string ops) |
| `EDI` | `DI` | — | — | Destination index (string ops) |

### 1.2 Segment Registers & Descriptor Tables
In 32-bit Protected Mode, memory segmentation is active:
- **Segment Selectors**: `CS` (Code), `DS` (Data), `SS` (Stack), `ES` (Extra), `FS` (Thread Local), `GS` (OS/Thread Local).
- **Selector Layout**: `[Index: 13 bits][TI (GDT/LDT): 1 bit][RPL (Requested Privilege Level): 2 bits]`.
- **Descriptor Tables**: Global Descriptor Table (`GDTR`) and Local Descriptor Table (`LDTR`) containing 8-byte segment descriptors (Base: 32 bits, Limit: 20 bits, Granularity `G`, Privilege `DPL`, Present `P`, Type).

---

## 2. Binary Instruction Encoding Differences from x86-64

1. **No REX Prefix**:
   - In 32-bit mode, opcodes `0x40` through `0x4F` encode single-byte `INC reg` and `DEC reg` instructions (not REX prefixes).
2. **Default Operand Size**:
   - Default operand and address size is 32 bits (controlled by code descriptor `D` bit).
   - Prefix `0x66` overrides operand size to 16 bits.
   - Prefix `0x67` overrides address size to 16 bits.
3. **ModR/M & SIB**:
   - No `ModR/M` RIP-relative mode; `Mod=00, R/M=101` encodes direct 32-bit absolute address `[disp32]`.

## 3. 32-Bit Calling Conventions & `ret N` Stack Cleanup

| Convention | Argument Passing | Return | Stack Cleanup | Callee-Saved | `Terminator.ret` Representation |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **`cdecl`** | Right-to-left on stack | `EAX` (64-bit in `EDX:EAX`) | **Caller** (`add esp, N`) | `EBX, ESI, EDI, EBP` | `Terminator.ret [] 0` |
| **`stdcall`** | Right-to-left on stack | `EAX` | **Callee** (`ret N`) | `EBX, ESI, EDI, EBP` | `Terminator.ret [] (bytesToPop := N)` |
| **`fastcall` (MS)** | `ECX, EDX`, rest on stack | `EAX` | **Callee** (`ret N`) | `EBX, ESI, EDI, EBP` | `Terminator.ret [] (bytesToPop := N)` |
| **`thiscall`** | `ECX` (`this`), rest on stack | `EAX` | **Callee** (`ret N`) | `EBX, ESI, EDI, EBP` | `Terminator.ret [] (bytesToPop := N)` |

In `gasm`, routines using callee-cleanup conventions pass `bytesToPop := N` to `Terminator.ret`, proving that the instruction emits `ret N` (`0xC2 imm16`) and that the caller's stack pointer is properly adjusted by $N + 4$ bytes.

---

## 4. System Transition & Privilege Rings

- **Privilege Rings**: Ring 0 (Kernel) to Ring 3 (User).
- **Syscall Mechanisms**:
  - Legacy Linux 32-bit: `int 0x80` (`EAX` = syscall number, arguments in `EBX, ECX, EDX, ESI, EDI, EBP`).
  - Fast Syscall: `sysenter` / `sysexit` (using `IA32_SYSENTER_CS`, `IA32_SYSENTER_ESP`, `IA32_SYSENTER_EIP` MSRs).
